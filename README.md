# QGIS-Python-Code-for-TGF
QGIS Code for Python Shell

QGIS'de nokta katmanlarında bulunan geoit ondülasyon verilerini, Trimble Grid Factory (TGF) yazılımında .ggf (Geoid Grid File) uzantılı geoit dosyaları oluşturmak amacıyla ISG 2.0 (International Service for the Geoid) ASCII grid standartlarına dönüştürmek için geliştirilmiş PyQGIS tabanlı bir Python kodudur.
